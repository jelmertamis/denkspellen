# Myrddins Toverschool (denkspellen)

Acht oefenspelletjes (blokken, overeenkomsten, patronen, cijfers onthouden, weegschaal, rekenen, runen zoeken en een kaartenreeks) om te wennen aan puzzels. Eigen opgaven, geen echte testvragen. Eén HTML-bestand, geen build.

Thema: een mysterieuze tovenaarsschool met tarotkaarten, kaartsymbolen (harten, schoppen, klaveren, ruiten), een twilight-lucht met bergen en Guus de uil als mascotte. Eigen ontwerp, zonder namen of beeldmateriaal uit bestaande boeken of films. Alle teksten zijn gericht aan het kind zelf.

- **Oefenen**: elk spel heeft niveaus; goed = niveau omhoog, fout = niveau omlaag.
- **Het tovenaarsexamen**: zeven onderdelen achter elkaar, zoals bij een echte test (startniveau op leeftijd, terugzakken, stoppen na drie fouten op rij, geen feedback). Eindigt met een geschat "speel-IQ". Dat is een schatting met verzonnen normen, geen echte IQ-score. De kaartenreeks is een extra les en telt niet mee.
