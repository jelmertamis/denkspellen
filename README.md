# Denkspellen

Zeven oefenspelletjes (blokken, overeenkomsten, patronen, cijfers onthouden, weegschaal, rekenen, tekens zoeken) om te wennen aan puzzels. Eigen opgaven, geen echte testvragen. Eén HTML-bestand, geen build.

- **Oefenen**: elk spel heeft niveaus; goed = niveau omhoog, fout = niveau omlaag.
- **De grote denktest**: alle zeven onderdelen achter elkaar, zoals bij een echte test (startniveau op leeftijd, terugzakken, stoppen na drie fouten op rij, geen feedback). Eindigt met een geschat "speel-IQ" voor de ouders. Dat is een schatting met verzonnen normen, geen echte IQ-score.
